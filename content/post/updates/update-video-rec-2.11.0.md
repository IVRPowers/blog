# Video REC v2.11.0
---

We are pleased to announce that our new **Video REC v2.11.0** has been released for suitable production services. This new version adds an IP allow-list for login and password-reset actions, plus full activity logging for blocked attempts. All users with previous maintained versions can upgrade today. Please contact our support!

```
## [2.11.0] - 2024-12-03

### Added
- Added IP Allowed feature for some pre login actions: login, login-otp and reset-password
- All user actions are now logged in the User Activity Logger when actions are blocked
```
