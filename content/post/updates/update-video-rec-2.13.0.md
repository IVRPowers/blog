# Video REC v2.13.0
---

We are pleased to announce that our new **Video REC v2.13.0** has been released for suitable production services. This new version migrates Slack usage notifications to the Slack Web API and improves the recordings interface. All users with previous maintained versions can upgrade today. Please contact our support!

```
## [2.13.0] - 2025-01-21

### Changed
- Updated Slack notification method to use Web API instead of Incoming Webhook
- Improved styles for child rows

### Fixed
- Fixed sidebar toggle icon when resizing screen
```
