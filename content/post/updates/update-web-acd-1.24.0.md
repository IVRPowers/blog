# Web ACD v1.24.0
---

We are pleased to announce that our new **Web ACD v1.24.0** has been released for suitable production services. This new version improves network transport configuration and voice user handling for realtime connections. All users with previous maintained versions can upgrade today. Please contact our support!

```
## [1.24.0] - 2026-02-13

### Added
- Added localnet and external IP to transport-wss template
- Added logic to update some of the voice users' properties

### Updated
- Changed the default values of rtp_symmetric and rtp_keepalive of a realtime user
```
