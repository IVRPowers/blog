# Video REC v2.14.0
---

We are pleased to announce that our new **Video REC v2.14.0** has been released for suitable production services. This new version adds Single Sign-On (SSO) via SAML, including full login, callback, and per-user auth provider configuration. All users with previous maintained versions can upgrade today. Please contact our support!

```
## [2.14.0] - 2025-05-23

### Added
- SSO integration via SAML, including login flow, callback handling, and user-level auth provider config

### Changed
- Renamed `processingTimeout` server config variable to camelCase for consistency

### Fixed
- Increased timeout on server and webapp for service deletion plus suppressed S3 CLI output to prevent buffer errors during bucket cleanup
```
