# Web ACD v1.22.0
---

We are pleased to announce that our new **Web ACD v1.22.0** has been released for suitable production services. This new version upgrades the platform to Node.js 18 LTS and fixes a database connection bottleneck that could block the application. All users with previous maintained versions can upgrade today. Please contact our support!

```
## [1.22.0] - 2025-10-10

### Updated
- Updated NodeJS runtime to v18 LTS
- Updated application libraries to latest versions

### Fixed
- A database connection bottleneck that could block the application
- Correctly loaded the image of the disconnected modal even when there is not internet connection
- Fixed a build error caused by the linter
- Adjusted Buefy events to @update:modelValue, and improved layout height and dark theme table styles
- A database queries race condition under certain circumstances
```
