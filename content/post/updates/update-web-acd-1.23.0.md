# Web ACD v1.23.0
---

We are pleased to announce that our new **Web ACD v1.23.0** has been released for suitable production services. This new version adds Hungarian language support and improves audio reliability on the very first call of a session. All users with previous maintained versions can upgrade today. Please contact our support!

```
## [1.23.0] - 2025-11-10

### Added
- Added Hungarian language (hu_HU) to the platform

### Fixed
- Fixed application iframe rendering if the target is not embed
- Fixed potential audio issues on the first call by requesting microphone permissions on connection (WebRTC warm-up)
```
