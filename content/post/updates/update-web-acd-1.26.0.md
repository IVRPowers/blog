# Web ACD v1.26.0
---

We are pleased to announce that our new **Web ACD v1.26.0** has been released for suitable production services. This new version adds Two-Factor Authentication (2FA) via email OTP to strengthen account security. All users with previous maintained versions can upgrade today. Please contact our support!
