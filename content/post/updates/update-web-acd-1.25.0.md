# Web ACD v1.25.0
---

We are pleased to announce that our new **Web ACD v1.25.0** has been released for suitable production services. This new version adds Progressive Web App (PWA) support, so agents can install Web ACD directly on their desktop or mobile device. All users with previous maintained versions can upgrade today. Please contact our support!
